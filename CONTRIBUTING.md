# Contributing

This repository is maintained as a historical archive. Changes are welcome when they improve security, accessibility, documentation, reproducibility, or compatibility while preserving the original educational experience.

Before proposing a change:

1. Keep all gameplay and optional comment data in the browser.
2. Do not add analytics, remote APIs, user tracking, email delivery, or credential-dependent services.
3. Run `npm test`, `npm run build`, and `npm audit --audit-level=high` from `frontend/`.
4. Describe any visible or scoring behavior change and include browser verification notes.
5. Do not include private research data, credentials, or third-party assets without documented redistribution permission.

Security reports should follow [SECURITY.md](SECURITY.md), not a public issue.
