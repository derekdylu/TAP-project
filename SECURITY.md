# Security Policy

## Supported version

Only the latest commit on the default branch is maintained. The retired Python, MongoDB, SendGrid, and Heroku deployment is not supported and must not be restored from Git history without a new security review.

## Reporting a vulnerability

If GitHub's private vulnerability-reporting form appears in the repository's **Security** tab, use it. If it is unavailable, contact the repository owner through their GitHub profile and ask for a private reporting channel without including sensitive details in the initial message.

Do not open a public issue containing credentials, personal data, or exploitation details.

Include the affected commit, browser or runtime version, impact, and minimal reproduction steps. Do not test against systems or data you do not own or have permission to access.
